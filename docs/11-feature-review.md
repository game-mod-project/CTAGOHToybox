# 추가 기능 검토 (P2, 2026-10-17)

백로그 P2 "원 요청 4번 추가 기능 검토"를 사용자가 진행하라고 했다(2026-10-17). 스펙 A·B와 참고 스펙에서 일부러 뺀 기능(백로그 8절)을 하나씩 보고, 지금 편집기로 얼마나 가까운지와 위험을 적었다. 이 문서는 손으로 고친다. 고른 것은 백로그에 새 항목으로 옮기고 스펙부터 쓴다.

판단 기준(AI 판단):
- **효용**: 지금 사용자가 하던 일(월드워 시야, 스탯 조정)을 줄이는가.
- **크기**: S 파일 한두 개 / M 여러 파일·화면 / L 설계부터.
- **확인 방법**: 게임 안 확인을 하지 않기로 했으므로(2026-10-16), 파일·편집기 검사만으로 맞는지 말할 수 있는가.

## 권하는 순서 (AI 판단)

1. **F1 일괄 규칙**: 월드워 작업에서 차종별로 같은 값을 450대에 넣는 데 프리셋 코드를 따로 썼다. 같은 일을 사용자가 앱에서 고를 수 있게 하면 다음 조정(속도·장갑·탄약 수)에 바로 쓴다. 규칙은 "대상(편집기 종류·폴더·이름) × 키 × 값(새 값·배수·더하기)"로 시작하고, 미리 보기 뒤 수정 목록에 넣는다.
2. **F2 SDL 원문 주석**: 작고 위험이 없다. 개발사 주석이 키 뜻의 가장 강한 근거라 D1(미확인 키)을 줄이는 데도 쓴다.
3. **F3 무기·탄약 복제**: 블록 복제의 다음 단계. F1 뒤에 본다.

나머지는 게임 안 확인 없이 맞는지 말할 수 없거나 사용자 파일·계정을 건드려 권하지 않는다.
