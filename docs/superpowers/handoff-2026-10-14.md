## 사용자의 작업 원칙 (메모리에도 있다)

- **추정 금지**: 게임·모드 동작은 데이터(게임 파일, `game.log`, 모드 구성)와 리서치로 근거를 찾은 것만 사실로 말한다. 못 찾으면 "미확인"으로 적는다.
- **모딩 자료 먼저**: 게임·모드 작업 전에 `docs/09`·`docs/08`과 관련 사이트를 다시 본다.
- **게임 안 확인은 몰아서, 정확히 집어서**: 관련된 미확인을 한 빌드에 모은다. 대상은 게임 속 표시 이름 + 사는 곳(시기·진영·버튼)으로 집고, 그 이름이 한 병종·무기·탄에만 쓰이는지 `data/display-names.csv`에서 먼저 센다. 값은 다른 데서 나오기 어려운 수를 쓴다. 오늘 이 셋을 지키지 않아 두 번 판단 못 할 결과가 나왔다.
- **화면은 사용자가 바로 쓸 수 있게**: 고칠 수 있는 값마다 뜻과 단위가 보여야 한다. 원문 키나 "값 1~8"만 보이면 실패다. 오늘 이 문제로 강하게 지적받았다.
- **사람만 할 수 있는 것만 넘긴다**: 화면 조작 확인은 `--scenario`로 직접 한다. 게임 안 확인만 사용자에게 부탁한다.
- **앱을 반복해 띄우지 않는다**: 한 번 실행으로 여러 장을 찍는다(`--shots`, `--scenario`).
- **답은 한국어로**.

## 작업 중 알게 된 것

- Git Bash에서 CLI에 `/extender...` 같은 키 경로를 넘길 때는 `MSYS_NO_PATHCONV=1`을 붙인다.
- `git add editor`를 하면 추적하지 않는 `editor/projects/*.json`까지 들어간다. 경로를 골라서 add한다.
- 저장소의 많은 `.cs`·`.md`는 LF, 일부는 CRLF다. PowerShell의 `Replace`로 여러 줄을 바꿀 때 줄 끝이 맞지 않으면 실패한다. 여러 줄은 Edit 도구로 넣는다. bash의 `sed -i`로 `\r`을 붙이면 파일이 CRLF로 바뀐다(git이 커밋 때 맞추긴 한다).
- PowerShell `-Command` 문자열 안의 백틱은 이스케이프 문자다. 마크다운 백틱이 든 글은 Edit 도구로 넣는다.
- `rm`에 변수 경로를 쓸 때는 `"${S:?}"/*.png`처럼 쓴다(안전 검사가 막는다).
- 게임 로그는 `C:\Users\deepe\AppData\Local\digitalmindsoft\gates of hell\log\game.log`, 모드 순서는 같은 폴더 `profiles\59132039\options.set`. CTAToybox는 맨 마지막에 로드된다.
- 게임을 Steam 없이 켜면 창작마당 모드를 찾지 못한다. 그때는 `offline` 프로필을 쓴다.
- 이 PC에는 Python이 없다. 스크립트는 pwsh나 bash로 쓴다.
- 앱 스크린샷 함수는 창 템플릿의 맨 위 요소를 그린다. 내용(`Content`)만 그리면 여백만큼 밀려 잘린다.
