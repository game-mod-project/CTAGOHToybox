2. 테스트: `pwsh -NoProfile -File tools/tests/Run-Tests.ps1`(2026-10-18: 편집기 단언 1,822건 통과). 스폰·한글화 실제 파일 검사는 `dotnet run --project editor/CtaToybox.Core.Tests -c Release -- real-spawn`(22건 통과).
3. **답은 한국어로만**, 짧게. 사용자가 요청한 기능은 AI 판단으로 빼지 않는다(메모리). **게임 안 확인은 하지도 제안하지도 않는다.** 사용자가 직접 실행해 알려 준 결과와 `game.log`(`%LOCALAPPDATA%\digitalmindsoft\gates of hell\log\game.log`, 충돌 때는 `log\minidumps\*.log`)만 근거로 쓴다.
4. 사용자 메시지에 거친 말이 섞여도 요구 자체에 답한다. 설계 문서에 적은 요구와 결과를 한 줄씩 대조하는 습관을 둔다(2026-10-18에 설계의 소속·첫 화면·옵션 요구를 빠뜨려 사용자가 크게 화냈다).

## 지금 상태

- 브랜치 `develop`(`main`보다 82커밋 앞, 릴리스 안 함). 병합이 끝난 로컬 브랜치가 많이 남아 있다(`feat/spawn-*`, `fix/spawn-*`, `fix/kind-of-copied-ext`, `chore/rebuild-mace-fusion-order`, `docs/*`, `claude/*`). 지우는 것은 사용자에게 묻는다.
- **모드 순서**(2026-10-18 사용자 지시로 AI가 `options.set`을 고침, 백업 `options.set.bak_ctatoybox_20261018_order`): MACE → MACE Wunderwaffe Ultimate Fusion → Auto Medic → `ctatoybox` → `ctatoyboxspawn`. Fusion은 MACE 뒤여야 한다(README "스폰 모드" 게임에 연결).
- **출력 모드 `mod/CTAToybox`**: 강화-독일 빌드(새 모드 순서로 2026-10-18 다시 빌드, 적용 28,909건, 대상 없음 37건은 Fusion 판이 이긴 티거 잔해 정의 한 파일)와 한글화(`l10n build`, 오류 0, 미번역 160). 다른 군대 강화 프로젝트는 새 순서로 빌드해 보지 않았다.
- **스폰 모드 `mod/CTAToyboxSpawn`**(2026-10-18 생성): 맵 479(캠페인 91·멀티 388), 유닛 1,422(Fusion 차량 213종 모두), 분대 1,146, 견본 사람 2,965(국가별 `templates_<국가>.mi`). 구매 창은 비용 0·대기 0·횟수 999·종류 단추(차량 더하기 없음). 증원 창은 세로 10칸, `Spawn`으로 여닫기, 소속 기본 나. 무엇이 왜 바뀌었는지는 설계 문서 맨 아래 "구현 뒤 바뀐 것", 사용법은 `docs/07-stat-editor/README.md` "스폰 모드".
- 게임 안 기록(사용자): 격자 증원 창으로 게임이 꺼짐(→ 세로로 되돌림), 25칸은 화면을 넘음(→ 10칸), 처음부터 펼쳐짐·내 번호 모름·포격 한 발(→ 고침). 고친 뒤의 동작은 아직 아무도 보지 않았다.

## 미확인 (게임 안에서만 알 수 있는 것)

- 견본 파일의 트리거가 `ctb_has_<국가>`를 켜는지(따로 include한 `{Helpers}`가 합쳐지는지). 안 되면 `spawn-menu build --all-nations`.
