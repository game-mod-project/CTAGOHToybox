4. 설계 문서의 요구와 결과를 한 줄씩 대조한다.

## 지금 상태

- 원격 저장소: https://github.com/game-mod-project/CTAGOHToybox (공개, 2026-10-19 첫 푸시). `main`은 릴리스, `develop`은 통합. 이제부터 작업 브랜치를 푸시해 `develop`으로 PR한다(CLAUDE.md "브랜치 전략").
- 모드 순서(59132039 프로필 `options.set`, 2026-10-19 사용자 지시로 AI가 고침, 백업 `options.set.bak_ctatoybox_20261019_reorder2`): MACE → MACE Wunderwaffe Ultimate Fusion → Auto Medic → `ctatoybox` → `ctatoyboxspawn` → `ctatoyboxspawn_ger·rus·usa`(eng·fin·jap은 꺼 둠). offline 프로필에는 `ctatoyboxspawn`이 없다.
- **게임 모드 화면에서 적용하면 순서가 화면 목록 순서(로컬 모드 먼저)로 다시 저장된다.** 2026-10-19에 두 번 그렇게 되어 `ctatoybox`가 MACE·Fusion 앞으로 가서 `Vision "ctb_vehicle" not found`로 꺼졌다. 게임이 꺼지면 game.log의 `Mod: activate mod` 순서와 options.set부터 보고, 순서는 options.set을 직접 고친다(사용자가 시킬 때만).
- 출력 모드 `mod/CTAToybox`: 강화-독일 빌드와 한글화(스폰 메뉴 글자 포함, 미번역 159는 원문이 빈 항목). 2026-10-19 사용자 결정으로 군대·병과·부대 이름을 음독 대신 뜻으로 번역했다(Heer → 육군 등, 그로스도이칠란트·브란덴부르거만 음독. 용어집과 한글화 설계 문서 2026-10-19 항목). DLC 캠페인 91개 미션 모두 번역 파일이 있다.
- 스폰 모드(2026-10-18~19 바꿈, 설계 `docs/superpowers/specs/2026-10-18-spawn-menu-nation-mods-design.md`):
  - 바탕 모드 `mod/CTAToyboxSpawn`: 맵 479, 메뉴(화면 496, 단추 4,420). 견본 자리는 모두 빈 조각.
  - **구매 창은 원래대로**(2026-10-19 사용자 결정, PR #5): 바탕 모드가 켜져 있으면 6개국 스커미시 로스터가 모두 비용 0으로 바뀌고 봇도 같이 썼다. 이제 기본으로 구매 창 파일을 내지 않고, `spawn-menu build --roster`일 때만 바꾼다(`--roster-add`는 차량까지 더한다).
  - 캠페인 맵도 국가 모드를 읽는다(2026-10-19 사용자 결정): 맵에 나오는 국가 가운데 켠 국가 모드의 견본만 로딩한다. 캠페인에서 메뉴를 쓰려면 그 국가 모드를 켠다. `--campaign-in-base`로 예전 판.
  - 국가 모드 6개 `mod/CTAToyboxSpawn_<국가>`: 멀티 맵 견본(ger 649·rus 394·usa 486·eng 505·fin 438·jap 554명). 함께 켜도 된다.
  - 메뉴 글자 한국어(409항목), 대표 유닛 그림, 국가별 지원·도구·소속 화면, 컨퀘스트 내 번호 추정(`id_1st_player`).
  - 게임 mods 폴더 정션: `CTAToybox`, `CTAToyboxSpawn`, `CTAToyboxSpawn_<국가>` 6개.

## 미확인 (게임 안에서만 알 수 있는 것)

- 국가 모드의 견본 파일이 바탕 모드의 빈 조각을 이기는지, 빈 조각 include가 문제없는지.
- 컨퀘스트 `id_1st_player`가 이 PC 사용자의 번호인지. 컨퀘스트가 아닌 멀티·스커미시는 첫 유닛 전에는 번호를 알 길을 찾지 못했다.
- 이전부터: 아군·적 AI(`relation`), 항공 폭격(`air_attack`), 포격 반경 단위, (`--roster`일 때) 구매 창 새 종류 단추와 봇의 비용 0 구매, 10칸이 화면에 들어가는지.
